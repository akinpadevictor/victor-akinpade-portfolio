# Victor Akinpade — Portfolio

Personal portfolio website for showcasing Data Science, AI, Business Intelligence and software projects.

## Built with
- HTML5
- CSS3
- JavaScript
- GitHub Pages

## Before publishing
Replace:
- `YOUR_USERNAME` with your GitHub username
- `YOUR_EMAIL@example.com` with your email
- `YOUR_LINKEDIN_USERNAME` with your LinkedIn username
- `#` project/demo links with your real links
- placeholder project images with screenshots in `/images`

## GitHub Pages
1. Create a GitHub repository, e.g. `portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the `images` folder.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save and wait for GitHub Pages to publish your site.
